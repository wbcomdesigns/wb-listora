Notes:
- Neutral "você" throughout: "Adicione", "Abra", "Faça login", "Envie" (imperative forms).
- Plural-Forms is `nplurals=2; plural=(n > 1);`, so 0 and 1 use the singular form.
- Plural entries whose singular msgid uses `%3$s` and plural uses `%2$s` ("%1$s %3$s updated.") use "%1$s item ..." for form 0, because `msgfmt -c` rejects `%3$s` in `msgstr[0]` when it is absent from `msgid_plural`.
- Existing mixed uses in the catalogue ("Anúncio" vs "Listagem", "Deletar" vs "Excluir") are not rewritten; this glossary governs new translations only.
