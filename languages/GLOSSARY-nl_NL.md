## Style notes
- Register: informal "je" / "jouw", never "u".
- Keep sentence case, trailing punctuation, ellipses and colons identical to the English.
- Plural-only entries where WordPress passes a singular noun (`%1$s %3$s updated.`): `msgstr[0]` drops the noun (`%1$s bijgewerkt.`) because msgfmt requires `msgstr[0]` to use only the `msgid_plural` arguments.
