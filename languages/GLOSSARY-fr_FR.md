Shared by WB Listora (Free) and WB Listora Pro. One English term, one rendering.

## Known inconsistency (existing strings, not changed)

Some pre-existing strings use "Annonce" as a tab/nav label and "Annonces" for "Listings"; both are kept. Some pre-existing strings use "Credits" in English. These were not changed, per the rule to never alter existing translations.
