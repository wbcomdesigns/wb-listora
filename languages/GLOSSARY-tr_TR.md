Notes:
- Existing mixed uses in the catalogue ("Listeleme", "Listing" and "İlan"; "Kolaylıkları") are not rewritten; this glossary governs new translations only.
- Polite "siz" throughout: "Girin", "Seçin", "Lütfen tekrar deneyin", "Sihirbazı yeniden çalıştırın".
- Turkish nouns do not inflect for number, so both plural forms are usually identical. Plural entries whose singular uses `%3$s` (WordPress post-type notices) use `%1$s %2$s` in both forms, because msgfmt requires msgstr[0] to fit the plural msgid too.
- Country names use the standard Turkish exonyms.
