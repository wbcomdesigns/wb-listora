# License Notice

> **Availability:** Pro only. Shown in the WordPress admin while WB Listora Pro has no valid license key. See [License Management](../getting-started/pro-license.md) for activating a key.

## What it says

While the site has no valid license, a warning appears in the WordPress admin:

> WB Listora Pro is running, but plugin updates are paused until this site has an active license. Your website features are unaffected. **Enter License Key**

The license controls updates only. Every Pro feature keeps working without a key. The notice exists so you know that updates, including security fixes, are not arriving.

The **Enter License Key** link opens **Listora → Settings → License**.

## Where it shows

| Screen | Behaviour |
|--------|-----------|
| **Plugins** screen | Always shown while there is no valid license. |
| **Listora → Settings → License** | Always shown while there is no valid license. |
| Other Listora screens | Shown until you click **Dismiss**. |
| Any other WordPress admin screen | Not shown. |

**Dismiss** hides the notice on the other Listora screens for you only. Other administrators still see it until they dismiss it too. It never goes away on the **Plugins** screen or the **License** tab, so you always find it where you manage plugins and the key.

Once the site has a valid license, the notice stops showing everywhere.
