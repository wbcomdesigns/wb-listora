# Video Scripts - Per-Feature 60-Second Clips

Ten focused short videos. Each one stands alone (for social, paid ads, or "feature deep-dive" thumbnails on your YouTube channel). Each ~60 seconds, scripted, with reference screenshots already in the image library.

---

## 1. Search & Filters (Free)

**On screen:** Visitor types "italian" → autocomplete → clicks Near Me → checks "Outdoor Seating" → results re-rank.
**Hook:** "What good is a directory if visitors can't find what they need in 3 seconds?"
**Body:**
> WB Listora's search is built on a denormalized index - not the slow `WP_Query` you've seen in lesser plugins. Type a keyword, see suggestions. Click Near Me, results re-sort by distance. Tick a facet, results update without a page reload. The URL state updates too - so visitors can share or bookmark exactly what they searched for. Scales to 100,000 listings without slowing down.
**CTA:** "Try the live demo on wbcomdesigns.com."

## Production notes

- **Pace:** 60 seconds is tight. Trim the body if needed, keep the hook + CTA pristine.
- **Captions:** Burn in for silent autoplay. Most social views are sound-off.
- **Format:** Master 16:9, re-cut 9:16 for Reels / Shorts and 1:1 for LinkedIn.
- **Branding:** End frame = WB Listora logo + URL + "Free / Pro" duality.
- **Length variance:** Aim 52-58s after final edit to fit YouTube Shorts' 60s ceiling.
