# WB Listora - Feature Announcement Email Template

Use this template whenever shipping a significant new feature. Fill in the bracketed sections. Send-time recommendation and A/B subject variants included.

---

## Subject Line Variants (A/B test one pair per send)

**Pair 1 - Benefit-led**
- A: {{Feature name}} is now in WB Listora {{version}}
- B: New in WB Listora: {{one-sentence benefit}}

**Pair 2 - Curiosity-led (for engaged lists)**
- A: We just shipped something you asked for
- B: {{Feature name}} - what it is, why we built it

**Recommendation:** Pair 1 performs better for cold or disengaged segments. Pair 2 works for highly engaged users who open consistently. Test send time: Tuesday or Wednesday, 9-11am recipient local time.

## Checklist Before Sending

- [ ] Feature name matches the one used in the changelog and docs
- [ ] Version number is correct
- [ ] Documentation link is live and tested
- [ ] "Who gets this" tier note is accurate (Free / Pro / both)
- [ ] Tested render in Gmail, Apple Mail, and Outlook
- [ ] Plain-text version prepared alongside HTML
- [ ] Unsubscribe link present and functional
- [ ] Send-time scheduled for recipient-local business hours

---

## Tone Notes

- Write in second person ("you can now…"), not first person ("we added…")
- Two to three sentences per paragraph maximum
- No "excited to announce" - start with what the user can do
- No marketing language: no "powerful," no "seamless," no "game-changing"
- If the feature has a limitation worth knowing, mention it honestly - it builds trust
