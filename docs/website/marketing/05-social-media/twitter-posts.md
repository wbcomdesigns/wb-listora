### Thread T-2 - How Hold-and-Commit works (4 tweets)

**1/4**
Most directory plugins charge vendors at submission, then discover the listing fails moderation. Now you owe a refund.

WB Listora Pro fixes this with Hold-and-Commit credits. Here is how it works.

**2/4**
Vendor picks a paid plan and submits.

Pro checks credit balance, HOLDS the cost (does not deduct), and marks the listing as Awaiting Credits or Pending.

If the balance is short, the listing pauses and the vendor sees exactly how many credits they need to top up.

**3/4**
Admin reviews and approves.

That is when credits COMMIT (debit) and the listing goes live with the right featured-rotation entitlement.

Admin rejects? Hold releases. Vendor's balance is untouched.

**4/4**
No silent debits. No refunds. No support tickets asking "where did my credits go".

That is one of 32 Pro feature modules in WB Listora Pro.

wblistora.com

### Thread T-3 - 6 anti-spam layers explained (6 tweets)

**1/6**
WordPress directory plugins die from review spam, claim spam and fake submissions.

WB Listora ships 6 anti-spam layers, all on by default in Free. A spammer has to defeat all 6.

Here is each layer.

**2/6**
Layer 1: Honeypot.

Every form has an invisible field. Bots fill it. Humans do not. Submission is rejected silently before any DB write.

Cost: zero CAPTCHA friction for real users.

**3/6**
Layer 2: Per-IP sliding-window rate limits.

Sane caps on review submits, claim submits, contact-form submits, search calls. Caps are filterable so high-traffic sites can tune them.

**4/6**
Layer 3: reCAPTCHA v3 or Cloudflare Turnstile.

Score-based and invisible. No more "click all the buses". Configurable threshold.

Layer 4: Akismet on reviews and claims.

**5/6**
Layer 5: Keyword blacklist.

Site-wide phrase list rejects matching content. You add the phrases that your category attracts.

Layer 6: URL density cap.

Reviews with more than N links are rejected before reaching Akismet. Stops link-stuffing.

**6/6**
All 6 layers are in Free. All on by default. All configurable via the Anti-Spam settings tab.

Plus Pro adds a Coming Soon mode to gate the whole directory while you tune.

wblistora.com
