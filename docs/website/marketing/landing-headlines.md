# Landing Page Headlines - H1 + Sub Variants

Five distinct H1 + sub combinations for A/B testing on wbcomdesigns.com. Each backed by a hero image already captured + a CTA pair (primary download Free, secondary explore Pro).

---

## Variant A - "The Outcome" framing

**H1:** Run a fully-monetizable business directory on WordPress.
**Sub:** Free covers the public directory - search, reviews, claims, frontend submission, anti-spam. Pro adds the business model: credit plans, lead capture, verification badges, comparison, moderators, and a reverse marketplace.
**Primary CTA:** Download Free at wbcomdesigns.com
**Secondary CTA:** See Pro features
**Hero image:** `home-frontend.png`

**Why this variant:** Outcome-first. Sells the END STATE. Best for cold visitors landing from generic "WordPress directory plugin" searches.

---

## Variant B - "The Speed" framing

**H1:** Your business directory, live in 30 minutes.
**Sub:** Install. Setup wizard. Demo data. Working directory with real-looking listings, search, filters, reviews - all working out of the box. Then customize at your pace.
**Primary CTA:** Install Free
**Secondary CTA:** Watch the 2-min tour
**Hero image:** `setup-wizard-step1.png` or `home-frontend.png`

**Why this variant:** Removes the "this'll take weeks" objection up front. Best for visitors coming from comparison posts ("Directorist vs ListingPro vs …").

---

## Variant C - "The Scale" framing

**H1:** Directory plugin built for 100,000 listings, not 100.
**Sub:** Denormalized search index, Action Scheduler vendored, single REST + IAPI namespace, 226 documented extension hooks. Built like infrastructure, not a side project.
**Primary CTA:** Get Free
**Secondary CTA:** See the technical brief
**Hero image:** `directory.png`

**Why this variant:** Sells to developers / agencies who've been burned by plugins that fall over at 5,000 listings. Best for visitors landing from technical / Stack Overflow / Reddit r/WordPress threads.

---

## Variant D - "The Business Model" framing (Pro-led)

**H1:** Charge vendors for their place in your directory. Without writing a single line of payment code.
**Sub:** WB Listora Pro adds credit-based pricing plans with Hold-and-Commit activation, 7 payment integrations (Stripe, PayPal, WooCommerce, WooSubs, MemberPress, PMPro, WooMemberships), coupons, paid-featured rotation - on top of everything Free already gives you.
**Primary CTA:** Buy Pro
**Secondary CTA:** Start with Free first
**Hero image:** `credits-and-plans.png` or `pricing-plans-admin.png`

**Why this variant:** For visitors already running a free directory and ready to monetize. Best for retargeting / email drip.

---

## Variant E - "The Marketplace" framing

**H1:** A directory where buyers and businesses meet - both ways.
**Sub:** Traditional directory plus the Needs Marketplace: buyers post what they want, businesses respond with quotes. Two flywheels, one plugin.
**Primary CTA:** See the Needs Marketplace
**Secondary CTA:** Install Free first
**Hero image:** `needs-marketplace.png`

**Why this variant:** Differentiates from every other directory plugin (none have this). Best for visitors searching for marketplace / B2B services plugin keywords.

## Below-the-fold sections (use in this order)

1. **What you get with Free** - 6-card grid (Search & Filters / Submission Wizard / Reviews / Claims / Spam Protection / Map) with `home-frontend.png` ambient screenshot.
2. **Pro adds the business model** - 6-card grid (Plans & Credits / Lead Forms / Verification / Comparison / Needs Marketplace / Moderators) with the matching feature screenshots.
3. **Built on modern WordPress** - block-themes, IAPI, REST-first, no shortcodes - 4 logos: Gutenberg / Interactivity / REST / Action Scheduler.
4. **Compatibility row** - payment integrations + theme integrations + multilingual.
5. **Customer quotes** - 3 testimonials (pull from existing customers; use placeholder if launching).
6. **Pricing table** - Free (always free) vs Pro (one-time or annual).
7. **Final CTA** - repeat hero CTA pair.

## Headline writing rules

- **No vague claims.** "Best directory plugin" → out. "Built for 100K listings" → in (backed by index architecture).
- **Concrete features over feature names.** "Multi-criteria reviews with photos" → out. "Rate Food, Service, Value, and Ambiance separately" → better.
- **No exclamation marks** in H1. Confidence is quiet.
- **No emoji** in H1 or sub. Pro feel.
- **Sub stays ≤ 28 words.** Two clauses max.
- **Match search intent.** Variant A for transactional, Variant B for evaluative, Variant C for technical, Variant D for retargeting, Variant E for differentiation.
