# WB Listora Marketing Kit

Last updated: 2026-05-24

---

## How to use this kit

Every file in this directory is a working asset - not a brief or a plan. Landing page copy is written. Email sequences are drafted. Video scripts are scripted. Brand assets define the rules. Before you write anything new for WB Listora, check whether a file here already does the job or can be adapted. When you add a new asset, add a row to the index below.

---

## Quick start

If you are writing a campaign from scratch, start with `07-brand-assets/messaging-guide.md` for naming rules, forbidden claims, and voice guidance. Then check `07-brand-assets/persona-profiles.md` to confirm which persona you are writing for. Use `07-brand-assets/seo-keywords.md` to find the right keyword for the page you are building. Finished copy? Check it against the "Hard constraints" section at the bottom of this file before it goes live.

## Hard constraints

These constraints apply to every piece of WB Listora marketing copy. Check before publishing.

**Naming**
- Always "WB Listora" - never "Listora" alone, never "Listora Plugin"
- "Free" and "Pro" are capitalised, standalone words

**Numbers - use these and only these**
- 226 documented hooks (120 actions + 106 filters)
- 55 REST endpoints in Free
- 65 additional REST endpoints in Pro
- 11 blocks in Free + 5 blocks in Pro
- 32 Pro feature modules
- 9 demo packs
- 6 anti-spam layers
- 7 payment integrations (WooCommerce, WooCommerce Subscriptions, MemberPress, Paid Memberships Pro, WooMemberships, Stripe, PayPal)
- WordPress 6.9+
- PHP 7.4+
- Scales to 100K listings

**Forbidden claims - never appear in any output**
- Razorpay integration (not supported)
- EDD / Easy Digital Downloads bridge (not supported)
- 199 hooks (outdated figure - correct number is 226)
- 6 payment integrations (correct number is 7)
- WordPress 6.7+ (correct minimum is 6.9+)
- Auto-renew or automatic renewal (renewal is always manual)
- 3x conversion or any unverified multiplier claim
- ~50ms search or any specific latency claim
- wordpress.org install count or active install numbers (WB Listora is private - no published install count)

**Style**
- No em-dashes (`-`) - use hyphen with spaces ` - ` or restructure the sentence
- No ALL CAPS for emphasis
- No multiple exclamation marks
- Max 1 emoji per content piece, never in product or feature names
- Use `{{PRICING_PLACEHOLDER}}` wherever pricing numbers would appear
