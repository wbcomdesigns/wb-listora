# Frequently Asked Questions

## Is WB Listora free?

The Free plugin covers listings, search, maps on a tile source of your choice, reviews, claims and moderation. [WB Listora Pro](../getting-started/activating-pro.md) adds Google and regional maps, credits and pricing plans, coupons, lead forms, analytics and more. See the [feature matrix](../feature-matrix.md).

## Which map does my directory use?

OpenStreetMap by default, drawn with the tile source you pick under **Listora > Settings > Maps**. With Pro you can switch to Google Maps, Kakao Maps, Naver Maps or AMap. If a provider's key is missing, the site falls back to OpenStreetMap. See [Map Settings](../settings/map-settings.md).

## Can visitors search by Plus Code?

Yes. A full Plus Code typed into the keyword box lists the listings within one distance unit of it. See [Search and Filters](../features/search-and-filters.md).

## Do I need Monetization on?

Only if you charge for listings. It is off by default on fresh installs. Turning it on adds the credit system, pricing plans, coupons and the payment webhook receiver, and a **Choose a Plan** step in the submission form. See [Credits and Plans](../features/credits-and-plans.md).

## Can I add my own map provider?

Yes, with the `wb_listora_map_providers` filter. See [Map Providers](../developer-guide/map-providers.md).

## Where do I move from another directory plugin?

See the migration guides for [GeoDirectory](../migrate-from-geodirectory.md), [Directorist](../migrate-from-directorist.md), [HivePress](../migrate-from-hivepress.md), [ListingPro](../migrate-from-listingpro.md) and [Business Directory Plugin](../migrate-from-business-directory-plugin.md).
