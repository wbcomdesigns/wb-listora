# Near me searches within a radius, shows how far, and obeys the site's unit

2.0.0: Near me carries the visitor position through the search, narrows results to a radius of 1, 5, 10, 25 or 50 (the owner's Settings > General > Near me radius is the starting value), and each card says how far it is in the site's distance unit. Short sentinel: `regression/near-me-radius.md`.

## Setup

- Record the settings to restore: `wp option get wb_listora_settings --format=json | jq '{near_me_radius,distance_unit}'` (here 5 and km).
- Reference counts straight from the API (no browser), for steps 2 and 4:
  ```bash
  wp eval 'foreach([1,5,10,25,50] as $r){$q=new WP_REST_Request("GET","/listora/v1/search");$q->set_param("lat",40.7128);$q->set_param("lng",-74.0060);$q->set_param("radius",$r);echo "r=$r total=",rest_do_request($q)->get_data()["total"],"\n";}'
  ```
  The counts must be non-decreasing and the browser must match them (allow for data changes between the two reads: re-read just before step 2).

## Steps

### 1. Near me adds position, radius and nearest-first (anonymous, 1440)
- **Action**: open `$SITE_URL/listings/`. Click the arrow button `.listora-search__near-me` (aria-label "Find listings near your location").
- **Expect**: the URL becomes `?listora_lat=40.713&listora_lng=-74.006&listora_radius=<owner default>&listora_sort=distance` (3 decimals: the exact position is not in the URL); the sort control reads "Nearest"; the picker `#listora-radius` (label "Near me, within") appears with options "1 km, 5 km, 10 km, 25 km, 50 km" and the default selected; the Filters badge counts 1; the result total drops below the unfiltered total and equals the reference count for the default radius.
- **Positive control**: before clicking, the picker has class `is-hidden` and the total is the full directory total.
- **On fail**: `src/interactivity/store.js::nearMe`/`searchImmediate`, `templates/blocks/listing-search/search.php` (picker), `includes/search/search-url-helpers.php::wb_listora_search_geo_from_url`.

### 2. Visitor changes the radius
- **Action**: choose "25 km", then "1 km".
- **Expect**: page reloads with `listora_radius=25` then `=1`; totals equal the reference counts (non-decreasing with radius); the picker keeps the chosen value after reload; page 1 resets (`listora_page` absent).

### 3. Each card says how far (same page)
- **Expect**: every `.listora-card` has `.listora-card__distance` reading "<n.n> km away" (one decimal, e.g. "0.2 km away"); with Nearest sort the numbers never decrease down the list; the first card's distance is <= the chosen radius.
- **Positive control**: on `/listings/` without Near me no card has `.listora-card__distance`.

### 4. Owner default and unit (administrator, wp-admin)
- **Action**: `$SITE_URL/wp-admin/admin.php?page=listora-settings&tab=general&autologin=1`. Set "Distance unit" = Miles (mi), "Near me radius" = 10, "Save Changes".
- **Expect**: success notice; a Near me URL WITHOUT `listora_radius` (open `/listings/?listora_lat=40.713&listora_lng=-74.006`) selects "10 mi" in the picker, options read "1 mi, 5 mi, 10 mi, 25 mi, 50 mi", cards read "<n.n> mi away", and the same nearest listing reads about 0.62 x its earlier km value.
- **Action**: set the radius to 15 (not in the preset list), Save.
- **Expect**: the picker now offers "15 mi" in sorted position and selects it (`wb_listora_near_me_radius_options()` adds the owner value).
- **Action**: set it to 0 or 501.
- **Expect**: the field clamps to its bounds (min 1, max 500) on save; never 0.
- **Restore**: radius 5, unit km.
- **On fail**: `class-settings-page.php` (~line 908, bounds ~136), `wb_listora_near_me_radius_options()` in `wb-listora.php`.

### 5. Bad input never breaks the page
- **Action**: open `/listings/?listora_lat=abc&listora_lng=1`, then `?listora_lat=999&listora_lng=1`, then `?listora_lat=40.7&listora_lng=-74&listora_radius=-5`.
- **Expect**: HTTP 200 each time; the first two ignore Near me entirely (full directory, picker hidden); the third clamps the radius to >= 1 and shows results; no PHP notice in `debug.log`.

### 6. Denied location
- **Action**: new context with geolocation permission denied; click the button.
- **Expect**: `.listora-search__error` (role=alert) shows the translated "location denied" message; the URL is unchanged; the directory still lists everything.

### 7. Map button parity
- **Action**: on a page with the Map block, click its "Near Me" button (`.listora-map__near-me-btn`).
- **Expect**: same URL contract as step 1; map and grid agree on the total.

### 8. 390px
- **Expect**: the picker wraps under the search bar, its select is >= 40px tall, no horizontal page scroll, the card distance text does not overlap the rating.

## Pass criteria

1. Near me yields lat/lng/radius/sort in the URL and a picker with the five radii; totals equal the API's reference counts.
2. Owner default seeds the picker; non-preset owner values are added; bounds hold.
3. Cards show distance only when a position is present, in the site's unit.
4. Invalid coordinates are ignored without error.
