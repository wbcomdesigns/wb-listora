# A number field can show as money, and a min/max pair reads as one range

2.0.0: a Number field has "Show as money (site currency)"; a field with `range_end` (min) joined to a partner with `range_start` (max) is shown once as "Salary $130K – $175K" on cards, the listing page and Compare, and read out as "Salary $130K to $175K". The Job type ships the pair as `salary_min` / `salary_max` (Job Board demo pack). Every consumer goes through `wb_listora_field_display()`.

## Steps

### 1. The listing page shows one range row (anonymous, 1440)
- **Action**: open `$SITE_URL/listing/mobile-engineer-ios/`.
- **Expect**: in the quick-info list `dl.listora-detail__quick-info` exactly one `<dt>Salary</dt><dd>$130K – $175K</dd>` (en dash U+2013 with spaces); NO separate "Salary Min" / "Salary Max" rows; in the Details tab the same single "Salary" row, plus "Salary Period: Per Year".
- **Positive control**: a Job whose min equals max (edit one in wp-admin to 150000/150000) shows just "$150K", and a Job with only a minimum shows "$150K" under "Salary"; proving the dash is not hard-coded.
- **On fail**: `wb_listora_field_display()` (`includes/class-template-helpers.php` ~1385), `templates/blocks/listing-detail/tabs.php` (~174, ~292).

### 2. Directory cards (anonymous)
- **Action**: `$SITE_URL/listings/?listora_type=job`.
- **Expect**: each job card meta item shows "$130K – $175K"-style text with `aria-hidden="true"`, preceded by a `.listora-sr-only` span "Salary $130K to $175K" (so a screen reader hears "to", not a dash). One range per card, not two numbers.
- **On fail**: `templates/blocks/listing-card/card-content.php` (~117) and `aria_label` in `wb_listora_prepare_card_data`.

### 3. Structured data carries the real numbers and currency
- **Action**: read the page's `application/ld+json` for the Job (JobPosting).
- **Expect**: `baseSalary` = `{"@type":"MonetaryAmount","currency":"USD","value":{"@type":"QuantitativeValue","minValue":130000,"maxValue":175000,"unitText":"YEAR"}}` (raw numbers, NOT "$130K"); plus the 2.0.0 JobPosting fixes: `title`, `datePosted`, `jobLocation` (Place > PostalAddress), `employmentType` "FULL_TIME", `jobLocationType` "TELECOMMUTE" for Remote.
- **Skip rule**: when an SEO plugin owns JSON-LD (Yoast/Rank Math/AIOSEO/SEOPress) Listora prints none; record "SEO plugin active" instead of FAIL.

### 4. Money follows the site currency and the editor switch (administrator)
- **Action**: Settings > General > Currency = EUR, Save; reload the listing and a card.
- **Expect**: "€130K – €175K" on page and card; JSON-LD `currency` = "EUR". Restore USD.
- **Action**: Listing Types > Job (`admin.php?page=listora-listing-types&edit=job`) > open "Salary Min" field > untick "Show as money (site currency)", Save Type.
- **Expect**: min now renders as a plain number ("130,000"), max still money, and the pair still joins as one range row "130,000 – $175K" (range is independent of money). Re-tick and save.
- **On fail**: `assets/js/admin/type-editor.js` (~486 `currency` checkbox), `wb_listora_format_card_value()` number case.

### 5. Compare reads the same (Pro Compare present)
- **Action**: add two jobs to compare, open `$SITE_URL/compare-listings/`.
- **Expect**: one "Salary" row per job with the range; no "Salary Min"/"Salary Max" rows.

### 6. Filtering is unaffected
- **Action**: Directory > choose type Job and open Filters.
- **Expect**: the filterable salary fields still appear as filters (the join is display-only: each bound stays its own field with its own `filterable` flag) and applying one narrows the total. Record the control labels and the URL parameter produced; this step has no fixed selector because the per-type filter controls are rendered client-side.

### 8. 390px
- **Expect**: the range does not wrap mid-number ("$130K – $175K" stays together or wraps at the dash); card meta row does not overflow; no horizontal scroll.

## Pass criteria

1. One joined range row on card, page and Compare; never two rows.
2. Screen-reader text says "to"; structured data holds raw numbers and the currency code.
3. The currency symbol follows Settings > General; the money switch is per field.
4. Equal bounds and a missing max degrade to a single value.

## Fail diagnostics

| Symptom | Likely cause | File |
|---|---|---|
| Two rows (Min and Max) | field lost `range_end`/`range_start` (saved type overwrote props) | `Listing_Type_Defaults` (~999), `Migrator` salary range repair (~640) |

| Dash read aloud | missing sr-only sibling | `card-content.php` |
